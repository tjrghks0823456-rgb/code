# Unbelievable 미디어 분석 파이프라인 및 대시보드 UI/UX 최종 개선 계획서

본 계획서는 **Unbelievable** 프로젝트의 Google Takeout 분석 엔진에서 발생하던 데이터 유실 및 오탐 필터링 문제를 개선하고, 복잡한 대시보드 리포트 화면의 인지 부하를 줄이기 위해 수행한 **3대 핵심 개선 조치**와 최종 사양을 정리한 문서입니다.

---

## 📌 3대 핵심 개선 영역 및 최종 사양

### 1️⃣ [백엔드] 시청 데이터 복구 및 타임스탬프·체류시간 보정 엔진 고도화
Google Takeout 데이터의 유실을 막고, YouTube의 기술적 제약으로 누락된 체류 시간을 합리적으로 복구하는 엄밀한 전처리 파이프라인입니다.
*   **시청/숏츠 분류 방안 완화**: watch?v= 주소 내에 숏츠 영상이 섞여 있는 기술적 한계를 분석하여, 영상 제목의 숏츠 특징 태그 및 메타데이터를 결합해 숏츠 데이터 유실을 최소화했습니다.
*   **Idle Capping (체류 시간 공백 보정)**: YouTube 기록에 재생 지속 시간이 누락되어 시각적 흐름 간 격차로 체류 시간을 시뮬레이션할 때, 장시간 브라우저 방치 등으로 발생하는 왜곡을 해결했습니다.
    *   인접 영상 간 간격이 30분을 초과하는 경우: 자리 비움으로 간주하고 기본값 `10분(600초)`으로 Capping 적용.
    *   30분 이내의 일반 공백: 실제 간격 그대로 보존하되 상한선 `30분(1800초)` 강제 지정.
    *   이벤트별로 계산된 기법(`metadata`, `timeline_gap`, `idle_capped`, `default_estimate`)을 `duration_estimation_method` 필드로 데이터베이스에 기록하여 분석 엄밀성을 확보했습니다.

### 2️⃣ [API & 지표] 데이터 결손 대응을 위한 품질 배너 및 신뢰도 지표 보강
불완전한 Takeout 데이터 품질 상태를 백엔드 엔진이 상시 검증하고, 이를 점수 계산 및 리포트 안내에 투명하게 반영하는 신뢰 장치입니다.
*   **TDS 카테고리 미분류 신뢰도 패널티**:
    *   형태소 및 NLP 카테고리 매칭 결과에서 "기타/미분류" 비중이 70% 이상일 때 대시보드 경고 문구를 포함하고, 80% 이상으로 극단적으로 치우치면 `TDS` (주제 다양성) 지표의 `confidence`를 `0.0`으로 강하시켜 신뢰도 하락을 리포트에 명시했습니다.
*   **품질 요약 및 디버깅 데이터 연동**:
    *   `data_quality_summary` 및 `analysis_debug` API 구조체를 추가하여 전체 파싱 실패율, 미분류율(카테고리 누락율), Capped 건수 등을 한눈에 전달하도록 개선했습니다.

### 3️⃣ [프론트엔드] 인지 부하 최소화를 위한 프리미엄 아코디언·탭 UI 컴팩트화
방대한 정보와 텍스트, 거대한 그래프들이 스크롤을 무한정으로 늘리던 난잡한 구조를 클릭 기반의 인터랙티브 아키텍처로 개편하여 UI 가독성을 극대화했습니다.
*   **관심사 마인드맵 3종의 탭(Tabs) 전환**:
    *   세로로 길게 나열되어 있던 3가지 관심사 마인드맵(검색 기반, 일반 시청, 숏츠 반복)을 하나의 컨테이너 안에서 **[🔍 직접 검색 맵] | [📺 일반 시청 맵] | [🔥 숏츠 반복 맵]** 탭 네비게이션으로 묶어, 유저가 원하는 맵 하나에만 몰입할 수 있도록 간소화했습니다.
*   **6대 핵심 점수 상세 가이드의 아코디언화**:
    *   6개 지표의 측정 근거, 주의 사항, 개선 행동 등의 방대한 텍스트 블록을 평소에는 숨겨두고, 사용자가 특정 지표 카드를 클릭할 때만 부드럽게 펼쳐지는 **원터치 아코디언 카드**로 개편했습니다.
*   **품질 안내 배너 및 기술 명세 서랍식 축소**:
    *   데이터 결손 안내용 다중 품질 경고 배너들을 **"💡 미디어 분석 데이터 품질 안내 (총 N건)"** 1줄 요약과 **[자세히 보기 ▼]** 토글 버튼으로 깔끔하게 정리했습니다.
    *   페이지 맨 하단에 위치해 스크롤을 길게 늘리던 **"분석 신뢰도 및 데이터 품질 상세 명세"** 영역 또한 **[상세 명세 펼치기 ▼]** 버튼으로 감싸 일반 유저의 시각적 노이즈를 제거했습니다.
