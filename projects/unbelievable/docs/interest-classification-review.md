# 관심사 분류 현황 진단 및 개선 결과 보고서 (Interest Classification Review & Results)

본 문서는 규칙 기반 관심사 분류 모델(Rule-based Classifier)의 한계점과 미분류 데이터의 발생 원인을 분석하고, 이를 극복하기 위해 수행한 규칙 개선 및 최종 분류 커버리지 측정 결과를 보고하기 위해 작성되었습니다.

---

## 1. 분류 개선 전/후 지표 비교 (Before & After)

테스트 시나리오 및 더미 시청/검색 기록 데이터(총 73건)를 활용하여 정량적인 분류 커버리지를 측정한 결과는 다음과 같습니다.

### 1) 검색어 관심사 맵 (Search Interest Map)
* **총 검색어 개수**: 12건
* **분류 개선 전**:
  * 분류 완료: 8건 (66.7%)
  * 분류 보류: 4건 (33.3%)
* **분류 개선 후**:
  * 분류 완료: **12건 (100.0%)**
  * 분류 보류: **0건 (0.0%)**
* **개선 효과**: 검색어 분류 커버리지 **33.3%p 상승** (완전 분류 달성)

### 2) 일반 영상 시청 관심사 맵 (Standard Video Interest Map)
* **총 영상 개수**: 48건
* **분류 개선 전**:
  * 분류 완료: 29건 (60.4%)
  * 분류 보류: 19건 (39.6%)
* **분류 개선 후**:
  * 분류 완료: **47건 (97.9%)**
  * 분류 보류: **1건 (2.1%)**
* **개선 효과**: 일반 영상 분류 커버리지 **37.5%p 상승**

### 3) 종합 지표
* **총 매핑 시도 데이터 (검색 + 시청 + 숏츠)**: 73건
* **종합 미분류(기타) 비율**:
  * 개선 전: 31.5% (23건 보류)
  * 개선 후: **1.4% (1건 보류)**
* **종합 분류 커버리지**:
  * 개선 전: 68.5%
  * 개선 후: **98.6%**

## 2. 대표 샘플 분석

### 1) 대표 미분류 샘플 (개선 후에도 보류된 샘플)
* `Watched 어그로 자극 기사 요약`
  * **원인**: 특정 주제(IT, 스포츠, 경제, 연예 등)가 뚜렷하지 않은 일반 사회 시사/뉴스 카테고리의 텍스트로, 오분류를 방지하기 위해 로컬 분류 규칙에서 의도적으로 미분류(기타)로 남겨두었습니다.

### 2) 새로 분류된 대표 샘플 (개선 전 미분류 -> 개선 후 정상 분류)
* `파이썬 장고 강의` ➡️ `IT/테크 -> 프로그래밍`
  * **해결**: "장고", "django" 프로그래밍 관련 핵심 키워드 매핑 추가.
* `차분한 ASMR 힐링 클래식` ➡️ `엔터테인먼트 -> 음악/아이돌`
  * **해결**: "asmr", "클래식", "힐링", "명상" 키워드 추가 및 스타일 태그 파싱.
* `골프 드라이버 스윙 레슨` ➡️ `스포츠 -> 골프`
  * **해결**: "골프", "golf", "스윙" 스포츠 소분류 키워드 사전 추가.
* `자바스크립트 강의` ➡️ `IT/테크 -> 프로그래밍`
  * **해결**: "자바스크립트" 한글 키워드 추가.
* `프로젝트 관리 실무` ➡️ `IT/테크 -> 프로그래밍`
  * **해결**: "프로젝트 관리", "pm" IT 비즈니스/개발 방법론 키워드 추가.
* `강아지 훈련 시키기` ➡️ `라이프스타일 -> 반려동물`
  * **해결**: 반려동물 소분류 카테고리 추가 및 "강아지", "고양이", "pet" 키워드 매핑.
* `자연어 처리 기술 공부`, `대규모 언어 모델 동향` ➡️ `IT/테크 -> AI`
  * **해결**: "자연어", "언어 모델", "딥러닝", "강화학습" 등 AI/ML 전문 키워드 매핑 추가.

## 3. 적용된 핵심 기술 및 구현 내용

1. **전처리 파이프라인 정밀화 (Normalize)**
   * 입력 제목/검색어에 대해 대소문자를 구분하지 않고 소문자로 변환하여 매칭합니다.
   * `[공식]`, `(ASMR)` 등 대괄호 및 소괄호 패턴을 정규식으로 파싱하여 내부에 기재된 내용을 추출하고 `secondary_tags`로 전달하며, 본문 매칭의 잡음을 제거했습니다.
2. **카테고리 매핑 확장 및 소분류 사전 추가**
   * 생활 스포츠 (`테니스`, `골프`, `낚시`, `캠핑`, `등산`) 및 IT 학계 기초 학술 용어 (`데이터베이스`, `네트워크`, `운영체제`, `자료구조`, `알고리즘`, `PM`)를 적극적으로 수용했습니다.
3. **스타일 키워드와 카테고리 결정 키워드 분리**
   * `ASMR`, `힐링`, `강의`, `레슨`, `공식` 등 스타일/포맷성 단어는 `secondary_tags`에만 보조 수치로 누적하고, 본문 매칭 단어들 중 카테고리를 결정하는 핵심 키워드가 실재하는 경우에만 primary category를 결정하도록 분리했습니다.
4. **넓은 키워드(Broad Keywords) 단독 매칭 방지**
   * `"추천", "리뷰", "비교", "가격"`은 단독으로 사용될 때 primary category를 결정하지 못하도록 차단하고 `secondary_tags` 및 `evidence`로만 동작하게 제한했습니다.
5. **YouTube 카테고리 매핑 테이블(`RAW_CATEGORY_MAP`) 최적화**
   * 유튜브 API가 전달하는 `music`, `gaming`, `pets & animals`, `comedy` 등 12개 이상의 표준 카테고리를 로컬의 10대 카테고리로 영리하게 재매핑하는 매핑 테이블을 구현하여 raw API 데이터와의 호환성을 극대화했습니다.
