# 반도체 장비 제어 시나리오 및 파이프라인 상세 설명

반도체 장비 제어 시나리오 및 파이프라인 상세 설명

개요 및 사용자 지정 시나리오 (Pipeline & Custom Scenario)
[기본 목표] 5장의 웨이퍼를 FOUP A -> A -> B -> C -> FOUP B로 이동. (스케줄링: 200ms 주기로 우선순위가 높은 작업을 먼저 수행)

 사용자 지정 최적화 시나리오 "입구 병목 해소" 로직입니다.

상황 조건:

1. Chamber B에 웨이퍼가 있음 (공정 중)
2. Chamber C에 웨이퍼가 있고 공정 완료됨 (C Ready)
3. Chamber A는 비어 있음 (A Empty)
일반적인 로직이라면: Priority 1인 C 배출(C -> FOUP B)을 먼저 하겠지만,
사용자 로직: C 배출보다 "A 투입(FOUP A -> A)"을 먼저 수행합니다. (이유: 입구(A)가 비어있을 때 빨리 채워넣어 전체 사이클 타임을 단축하기 위함)

동작 순서:

1. FOUP A Pickup: FOUP A에서 웨이퍼를 꺼냅니다.
2. Chamber A Place: 곧바로 Chamber A에 웨이퍼를 안착시킵니다.
3. 그 후 다음 사이클에서 C 배출이 일어납니다.

상세 동작 시퀀스 (Detailed Sequence)
로봇 동작은 하드웨어 인터락을 철저히 준수하며 수행됩니다. FOUP과 Chamber의 동작 방식이 다르므로 구분하여 기술합니다.

A. 픽업 시나리오 (Pick Sequence)

[A-1. FOUP 픽업 (FOUP Pickup)] FOUP은 도어(Door) 제어가 필요 없습니다.

1. 이동: 로봇이 해당 슬롯의 안착 위치(Load Z)로 이동.
2. 전진 (Forward): 실린더 전진 -> 2초 대기 -> 0.5초 안정화.
3. 흡착 (Vacuum ON): 진공 ON -> 0.2초 대기.
4. 상승 (Lift Up): 로봇이 상승 위치(Up Z)로 이동 (웨이퍼 들어올림).
5. 후진 (Retract): 실린더 후진 -> 센서 확인(DI 13) -> 0.5초 안정화.





[A-2. 챔버 픽업 (Chamber Pickup) -  도어 제어 포함] 챔버에서 꺼낼 때는 도어를 열고 닫는 과정이 필수입니다.

1. 이동: 로봇이 챔버 앞 안착 위치(Load Z)로 이동.
2. 도어 오픈 (Door Open):
3. 로봇 정위치 확인.
4. DO Open 출력 -> DI Open 센서 대기.
5. 대기 2.0초: 문 열린 후 기류 안정화.
6. 전진 (Forward): 실린더 전진 -> 2초 대기 -> 0.5초 안정화.
7. 흡착 (Vacuum ON): 진공 ON -> 0.2초 대기.
8. 상승 (Lift Up): 로봇이 상승 위치(Up Z)로 이동.
9. 후진 (Retract): 실린더 후진 -> 센서 확인 -> 3.0초 대기 (안전 확보).
10. 도어 클로즈 (Door Close): DO Close 출력.


B. 안착 시나리오 (Place Sequence)

[B-1. FOUP 안착 (FOUP Place)]

1. 이동: 로봇이 해당 슬롯의 상승 위치(Up Z)로 이동.
2. 전진 (Forward): 실린더 전진 -> 2초 대기 -> 0.5초 안정화.
3. 진공 해제 (Vacuum OFF):
4. 진공 OFF.
5. 배기 펄스(Exhaust): 0.5초간 배기를 쏘아 웨이퍼 분리.
6. 하강 (Lift Down): 로봇이 안착 위치(Load Z)로 내려놓음.
7. 후진 (Retract): 실린더 후진 -> 센서 확인 -> 0.5초 안정화.
8. 상승 (Lift Return): 빠져나온 후 다음 동작을 위해 다시 상승 위치로 복귀.


[B-2. 챔버 안착 (Chamber Place) - ★ 도어 제어 포함]

1. 이동: 로봇이 챔버 앞 상승 위치(Up Z)로 이동.
2. 도어 오픈 (Door Open):
3. DO Open 출력 -> DI Open 센서 대기.
4. 대기 2.0초.
5. 전진 (Forward): 실린더 전진 -> 2초 대기 -> 0.5초 안정화.
6. 진공 해제 (Vacuum OFF):
7. 진공 OFF.
8. 배기 펄스(Exhaust): 0.5초간 배기.
9. 하강 (Lift Down): 로봇이 안착 위치(Load Z)로 내려놓음.
10. 후진 (Retract): 실린더 후진 -> 센서 확인 -> 3.0초 대기.
11. 도어  클로즈 (Door Close): 
DO Close 출력.
대기 1.0초: 밀폐 확인.
공정 시작: 챔버 램프 ON.
공정 끝 : 픽업되기 전까지 챔버 램프 깜빡임
핵심 안전 인터락 (Key Interlocks)

실린더 이동 제한: 실린더 전진(Forward) 상태에서는 좌우(LR) 이동 불가.

도어 오픈 제한: 로봇이 해당 챔버 앞에 없으면 도어 오픈 불가.

긴급 정지: 비상시 모터 전원 차단(Servo OFF) 및 진공 해제.
