# Etch HMI Result Report

This folder contains the project result-report deck for the Etch Load Lock HMI / Flask monitoring project.

## Files

- `etch-hmi-result-report.pptx`: editable PowerPoint result report, strengthened to 10 slides.
- `etch-hmi-result-report-contact-sheet.png`: thumbnail overview of the 10-slide deck.
- `wpf-main-screen.png`: captured WPF HMI main screen after admin login.
- `flask-realtime.png`: captured Flask realtime monitoring screen.
- `flask-modules.png`: captured Flask module status screen.
- `flask-ai.png`: captured Flask AI diagnosis screen.
- `wpf-schematic-zoom.png`: enlarged evidence crop for the WPF equipment schematic.
- `flask-modules-table-zoom.png`: enlarged evidence crop for the Flask module table.

## Capture Notes

- WPF was built successfully with `dotnet build etch_ui.csproj`.
- The WPF capture used the project default admin account created in `App.xaml.cs`.
- Flask screenshots use the real `etch_dashboard.html` UI with report-demo API payloads injected for readable presentation evidence.
- The strengthened deck was exported as 10 slides and verified as a valid PPTX archive with 10 slide XML files and embedded media.
